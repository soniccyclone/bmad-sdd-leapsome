## 5. Remaining Gaps (the ~20%)

These are the non-trivial uncovered lines worth flagging:

### Backend
- **`src/db/index.ts` connection setup (~28% uncovered)** -- the missing `DATABASE_URL` throw and pool teardown paths. Low-value to test (infrastructure boundary).
- **`src/app.ts` branches (28.57%)** -- CORS/rate-limit env-var fallbacks. Some live only in production env.
- **`src/routes/todos.ts` (~25% uncovered)** -- mostly the `isDbError` 503 paths under specific Postgres error codes. Hit by integration when the DB is killed mid-request, not by the standard suite.

### Frontend
- **`src/hooks/` (~33% uncovered)** -- the deepest gap. Optimistic-update rollback paths and last-page-detection branches in `useCreateTodo`/`useUpdateDescription` are partially covered; some cache-invalidation edge cases remain.
- **`src/App.tsx` functions (33.33% -- 2/6)** -- a few callback handlers exercised only via E2E, not the component test.

None of these gaps represent a correctness risk in the happy path or the documented error paths. They are primarily defensive code and infrastructure plumbing.

## 6. How to Reproduce

```bash
make coverage              # runs both packages with v8 coverage
                           # outputs HTML to packages/{backend,frontend}/coverage/
```

CI publishes the combined number to `.github/badges/coverage.json` on every push to `main`.
